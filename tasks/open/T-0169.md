## Goal
The build warns when the text of a built page has a round or square bracket, a curly double quote or a straight double quote that is opened and never closed (or closed and never opened), and never stops the build for it.

## Why it matters
Text typed fast, pasted from Word or imported from Blogger often has "(see the table below" with no closing bracket, or a quotation that starts and never ends. A reader sees it at once. Nothing in the build read the brackets or quotes of the text.

## Steps
1. New `site/scripts/bracket-check-lib.mjs` with `checkBrackets(html)` (reads the title and the body text; an inline tag leaves no gap, a block tag ends a paragraph, a `br` does not; comments and script, style, template, textarea, pre, code, kbd, samp, svg, noscript and select blocks skipped; attributes and the meta description not read; one message per kind with a count; no errors).
2. Kinds: a round or square bracket that is not matched, counted per paragraph; a curly double quote that is closed with none open or opened and never closed; a straight double quote left open at the end of the page.
3. Left out: a smiley (`:)`), a list marker with a closing bracket only (`1)`, `a)`, `iv)`), a quotation that runs over several paragraphs (a paragraph that starts with a quote mark while the last quote is open continues it), a straight quote after a digit (`5'10"`), a German style quote (`low opening mark, curly closing mark`), the single quote and the apostrophe, code.
4. `site/scripts/validate-html.mjs`: import it, run it on every built page, name it in the first comment line.
5. New test `bracket-check.test.ts` (65 cases, with a fake dist folder run of the real gate).
6. Run the whole test suite and the real build, then the gate on a throw away copy of the real build with the three slips added.
7. Version 0.101.171, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A page with `(see below`, `"no` and `\u201cmaybe` open gives three warnings that name the page; the build still passes.
- `:)`, `1) one 2) two`, `5'10"`, a quotation over two paragraphs, `&quot;no&quot;` pairs and text in `pre` or `code` pass with no message.
