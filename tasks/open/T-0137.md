## Goal
The build stops when a built page loads a script or a style sheet from `http://` or holds a `<script>` with an empty `src`; it warns on a script with a `src` that also holds text, async or defer on an inline classic script, nomodule on a module script, the same classic script loaded twice and `document.write(` in an inline script.

## Why it matters
A browser blocks a script or a style sheet from `http://` on an `https` page and tells the reader nothing: the page loses its look or a function stops. A script or snippet pasted by hand (PLAN 37, the Ads screen) can carry such an address. The owner cannot see this in the dashboard preview.

## Steps
1. New `site/scripts/script-check-lib.mjs` with `checkScripts(html)` (one pass over the script and link tags, comments and templates skipped).
2. `site/scripts/validate-html.mjs`: import it and run it on every built page.
3. New test `script-check.test.ts` (56 cases, with a fake dist folder run of the real gate and a read of the base layout).
4. Run the whole test suite and the real build, then the gate on throw away copies of the real build with bad markup added.
5. Version 0.101.139, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A script from `http://`, a style sheet from `http://` and a script with an empty `src` fail the gate.
- `document.write(` only warns.

## Evidence
- Files changed: the paths of this card (new files: the library, the test and this card). Nothing in `site/src/`, `site/config/` or `site/content/` changed.
- Check: `npm test`: 227 files and 5441 tests passed (before: 226 and 5385). `npm run build` ended with `Validation passed.` on today's real build with no new message (with `SITE_URL` set).
- Found while building: my first version warned about `async` with `defer` on one script, and today's real contact page (the Cloudflare Turnstile snippet) wrote both, so the rule was a false alarm and was removed before it shipped. A test now keeps that snippet passing.
- Throw away copies of the real build in `/tmp` (not in the ZIP): a script from `http://`, a style sheet from `http://` and a script with an empty `src` each ended with exit code 1 and `Validation failed`; `document.write(` ended with exit code 0 and a warning.
