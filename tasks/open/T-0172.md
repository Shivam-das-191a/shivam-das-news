## Goal
The build warns when the text of a built page has a full stop, question mark or exclamation mark glued to the capital word that follows it, and never stops the build for it.

## Why it matters
Text pasted from Word or imported from Blogger often loses the space between two sentences (`left.Then`, `Why?Because`), most often where a line break was dropped. A reader sees each one at once and trusts the site a little less. The punctuation check of v0.101.170 reads a missing space after a comma or semicolon only; nothing read the end of a sentence.

## Steps
1. New `site/scripts/sentence-space-check-lib.mjs` with `checkSentenceSpacing(html)` (reads the title and the body text of every page; only the letters A to Z are read; an inline tag leaves no gap, a block tag, a `br` and a character reference end the run; comments and script, style, template, textarea, pre, code, kbd, samp, svg, noscript and select blocks skipped; attributes and the meta description not read; one message per page with a count; no errors).
2. The slip: a word of 2 or more letters, then `.`, `?` or `!`, then at once a word that starts with a capital letter and has 2 or more small letters after it.
3. Left out: a full stop after the short form of a title or a name (Mr, Mrs, Ms, Dr, St and the like), an address that starts with `www`, an e-mail address, an ellipsis, a single letter, a number, a word after the mark with one small letter, code, text in another script.
4. `site/scripts/validate-html.mjs`: import it, run it on every built page, name it in the first comment line.
5. New test `sentence-space-check.test.ts` (72 cases, with a fake dist folder run of the real gate).
6. Run the whole test suite and the real build, then the gate on a throw away copy of the real build with slips added.
7. Version 0.101.174, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A page with `left.Then` and `Why?Because` gives one warning that names the page and counts 2 places; the build still passes.
- Clean sentences, `Mr.Smith`, `www.Site.com`, an e-mail address, an ellipsis, a single letter, a number, text in `pre` or `code` and text in another script pass with no message.
