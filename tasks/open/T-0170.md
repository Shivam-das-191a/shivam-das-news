## Goal
The build warns when the text of a built page has a space just inside a bracket, no space before an opening bracket that follows a word, or no space after a closing bracket that is followed by a word, and never stops the build for them.

## Why it matters
Text typed fast, pasted from Word or imported from Blogger often has "( see below )", "said(see below)" or "(see below)then". A reader sees each one at once and trusts the site a little less. Nothing in the build read the gaps around brackets.

## Steps
1. New `site/scripts/bracket-space-check-lib.mjs` with `checkBracketSpacing(html)` (reads the title and the body text; an inline tag leaves no gap, a block tag ends the run, a `br` does not; comments and script, style, template, textarea, pre, code, kbd, samp, svg, noscript and select blocks skipped; attributes and the meta description not read; one message per kind with a count; no errors).
2. Kinds: a space just inside a bracket (after `(` or `[` before a letter or digit, or before `)` or `]` after a letter or digit); no space before an opening round bracket after a word of 3 or more letters that starts a word of 3 or more letters; no space after a closing round bracket that holds 3 or more characters and is followed by a word of 2 or more letters.
3. Left out: a smiley (`:(`, `:)`), `word(s)` and a bracket with 1 or 2 characters, `f(x)`, `Title(2020)`, `( ... )`, a gap written as `&nbsp;`, an address such as `Rome_(city)`, code.
4. `site/scripts/validate-html.mjs`: import it, run it on every built page, name it in the first comment line.
5. New test `bracket-space-check.test.ts` (57 cases, with a fake dist folder run of the real gate).
6. Run the whole test suite and the real build, then the gate on a throw away copy of the real build with the three slips added.
7. Version 0.101.172, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A page with `( see below )`, `said(see below)` and `(see below)then` gives three warnings that name the page; the build still passes.
- `:(`, `:)`, `word(s)`, `f(x)`, `Title(2020)`, `( ... )`, `(&nbsp;word&nbsp;)` and text in `pre` or `code` pass with no message.
