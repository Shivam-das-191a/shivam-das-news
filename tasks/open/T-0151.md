## Goal
The build stops when a share tag has a name that is a typo of a real one (`og:titel`), a `twitter:card` or `og:type` that is a typo of a real value, an `og:image:width` or `og:image:height` that is not a whole number, an `og:locale` not written like `en_US`, an article time that is not a real ISO date, or a `twitter:image` that is not a full address; it warns on an empty content, an unknown value, a tag written twice and a few other small things.

## Why it matters
`<meta name="twitter:card" content="summary_large_img">` looks right, but the card falls back to a plain link. `<meta property="og:titel">` is not read at all and `og:locale` written `en-US` is not the form Facebook reads. `head-check-lib.mjs` reads only "the tag is there" and "the address is full", so a typo of a name or a wrong value passed. Old Blogger posts (XML import) and a snippet pasted by hand (PLAN 37) can carry these.

## Steps
1. New `site/scripts/share-check-lib.mjs` with `checkShareTags(html)` (one pass over all meta tags; comments, script, style and template skipped; a content written as a template expression is not read).
2. `site/scripts/validate-html.mjs`: import it and run it on every built page.
3. New test `share-check.test.ts` (65 cases, with a fake dist folder run of the real gate and a read of the base layout, the search page and the 404 page).
4. Run the whole test suite and the real build, then the gate on throw away copies of the real build with bad markup added.
5. Version 0.101.153, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.
