## Goal
The post editor has an Advanced fold in the Search engine listing box that shows the share card preview and lets an editor set the share title, description, picture, the canonical address and the schema type, using the rules of Part 5a.

## Why it matters
Part 5a built the data and the rules but nobody could reach them from the dashboard. This part makes them usable, with the role lock for the canonical, and nothing else.

## Steps
1. Read `NEWS_WEBSITE_PLAN.md` 33.2 and the code of Part 5a.
2. Add the fold to `listing-box.js` (only drawn when the share inputs are given).
3. Create the share inputs in `app.js`, move the canonical and schema type into the fold, lock the canonical by role, check the role again at Save.
4. Style it in `admin.css`.
5. Write the tests, make deliberate mistakes to prove they fail.
6. Bump the version, write the changelog, update `CODING_PLAN.md` and `INCOMPLETE.md` (`VERSIONING.md`).

## Done when
- `npm test`, `npm run build` and `npm run preflight` pass; older tests pass unchanged.
- Press Advanced in a post: the card preview follows typing; a writer sees the canonical locked and cannot save one.
