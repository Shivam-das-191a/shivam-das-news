## Goal
The live push Worker runs the version in the repository.

## Why it matters
`INCOMPLETE.md` says the Worker was not redeployed since v0.101.0, so live push behaviour may differ from the code and tests.

## Steps
1. In `workers/push` run `npx wrangler deploy`.
2. Send one test notification to the owner's own device from the dashboard.

## Done when
- The deploy output shows a new version id.
- The test notification arrives.

## Evidence
(Deploy output line, a note that the test arrived.)

## If it goes wrong
In Cloudflare, Workers, `push`, Deployments: roll back to the previous version.

## Stop and ask the owner if
- The deploy asks for a secret that is not set (do not paste it in any file).

## Log
- 2026-11-17, Claude. `VAPID_PUBLIC_KEY` in `workers/push/wrangler.toml` now holds the public key of `site/config/push.json` (v0.101.36), so a deploy no longer writes an empty value over the dashboard. **Not done:** the deploy itself and the test notification (owner). The private key and subject secrets must belong to this public key; if unsure, make a new pair with `npm run vapid` on your own computer and change both files and both secrets.
