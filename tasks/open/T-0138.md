## Goal
The build stops when a built page declares a character set other than UTF-8, holds a `<meta http-equiv="refresh">` with a delay over 0 seconds, has a `<base href>` from `http://` or has more than one `<base>`; it warns on a refresh of 0 seconds to an address, a `<base>` with no href and no target, a character set declared twice and a `<meta charset>` after the first 1024 bytes.

## Why it matters
A wrong character set shows letters and quotes as strange signs. A refresh moves or reloads the page under the reader and a screen reader cannot stop it. A `<base>` from `http://` or a second `<base>` changes every link of the page with no sign. A page or snippet written by hand (PLAN 37) can carry any of these and the dashboard preview shows none of them.

## Steps
1. New `site/scripts/meta-check-lib.mjs` with `checkMeta(html)` (one pass over the meta and base tags, comments, script, style and template skipped).
2. `site/scripts/validate-html.mjs`: import it and run it on every built page.
3. New test `meta-check.test.ts` (46 cases, with a fake dist folder run of the real gate and a read of the base layout).
4. Run the whole test suite and the real build, then the gate on throw away copies of the real build with bad markup added.
5. Version 0.101.140, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A character set other than UTF-8, a refresh with a delay and a base from `http://` fail the gate.
- A refresh of 0 seconds and a character set declared twice only warn.
