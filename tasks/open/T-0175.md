## Goal
The build warns when the body text of a built page has a pile of exclamation or question marks (`Wow!!`, `Really???`, `What?!?!`), and never stops the build for it.

## Why it matters
Text pasted from a chat, a forum or a social post often keeps its piled marks. A news reader sees each one at once and takes the site for a rumour page. The title and heading check of v0.101.84 reads only the title and the headings; nothing read the body text.

## Steps
1. New `site/scripts/exclaim-check-lib.mjs` with `checkExclaimRuns(html)` (reads the body text of every page; the title and the h1 to h3 blocks are left to the older check; an inline tag leaves no gap, a block tag, a `br` and a character reference end the run; comments and script, style, template, textarea, pre, code, kbd, samp, svg, noscript and select blocks skipped; attributes and the meta description not read; one message per page with a count and the first run; no errors).
2. The slip: a run of 2 or more of the marks `!` and `?` that is not exactly `?!` or `!?`.
3. Left out: the single pair `?!` or `!?`, one mark alone, a word that holds a web address, code, full width marks of other scripts.
4. `site/scripts/validate-html.mjs`: import it, run it on every built page, name it in the first comment line.
5. New test `exclaim-check.test.ts` (67 cases, with a fake dist folder run of the real gate).
6. Run the whole test suite and the real build, then the gate on a throw away copy of the real build with slips added.
7. Version 0.101.177, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A page with `Wow!!` and `Really???` gives one warning that names the page and counts 2 places; the build still passes.
- Single marks, `?!`, `!?`, a web address with marks, text in `pre` or `code`, and a pile in the title or a heading (left to the older check) pass with no message from this check.

## Evidence
- Files changed: the paths of this card (new files: the library, the test and this card). Nothing in `site/src/`, `site/config/` or `site/content/` changed. No older test changed.
- Check: `npm test`: 265 files and 7557 tests passed (before: 264 and 7490). `npm run build` ended with `Validation passed.` on today's real build with no new message (with `SITE_URL` set).
- Throw away copy of the real build in `/tmp` (not in the ZIP): a paragraph with `Wow!! That was fast. Is it true?! Yes. Really???` added to `index.html` gave one warning that named the page and counted 2 places, and the gate still ended with `Validation passed.`.
