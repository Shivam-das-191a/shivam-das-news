## Goal
`INCOMPLETE.md` holds only the newest open items and the decision table; old "Open Items After vX" blocks and old changelog entries live in `docs/archive/`, with nothing lost.

## Why it matters
`INCOMPLETE.md` is about 27,800 words and `CHANGELOG.md` about 43,000. No assistant reads that in one session, so open work is easy to miss.

## Steps
1. Wait for decision 43 (the size budgets).
1b. The tool exists since v0.101.11: in `site/` run `npm run docs:archive` to see the plan (it changes nothing), then `npm run docs:archive -- --apply`.
2. Move every "Open Items After vX" block except the newest two from `INCOMPLETE.md` to `docs/archive/INCOMPLETE-<range>.md`.
3. Move changelog entries older than the cut-off to `docs/archive/CHANGELOG-<range>.md`; keep the newest entry at the top of `CHANGELOG.md` and a line that names the archive files.
4. Check the word counts: the archive plus the remaining file equals the old file.
5. Run the tests.

## Done when
- `INCOMPLETE.md` and `CHANGELOG.md` are within the budgets of decision 43.
- No text was lost (the word counts add up).
- `npm test` passes.

## Evidence
(Word counts before and after, the archive file names, the test summary.)

## If it goes wrong
Revert the commit; the files return as they were.

## Stop and ask the owner if
- A test reads `CHANGELOG.md` or `INCOMPLETE.md` and fails after the move (the fix would touch tests: ask).
