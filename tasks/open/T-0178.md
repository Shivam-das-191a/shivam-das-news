## Goal
The build warns when a built page holds the same paragraph twice in a row, and never stops the build for it.

## Why it matters
A story pasted two times, a block copied by mistake or an import that ran two times leaves a paragraph written again right after itself. A reader sees it at once and trusts the site a little less. The check of doubled words (Part 8bp) reads one word only; nothing read a whole paragraph.

## Steps
1. New `site/scripts/repeat-check-lib.mjs` with `checkRepeatedParagraphs(html)` (reads every `<p>`; the text is read with tags removed, a `br` as a space, a blank written as `&nbsp;` as a plain space, runs of spaces as one and capitals as small letters; comments and script, style, template, textarea, pre, code, kbd, samp, svg, noscript and select blocks skipped; attributes and the meta description not read; one message per page with a count and the first five words; no errors).
2. The slip: a `<p>` of 8 or more words whose text is the same as the text of the `<p>` right before it. Three copies in a row are two places.
3. Left out: a paragraph of 7 words or fewer, two equal paragraphs with any other `<p>` between them, the same text in a list item, a heading or a table cell, an empty paragraph, code and preformatted text.
4. `site/scripts/validate-html.mjs`: import it, run it on every built page, name it in the first comment line.
5. New test `repeat-check.test.ts` (70 cases, with a fake dist folder run of the real gate).
6. Run the whole test suite and the real build, then the gate on a throw away copy of the real build with a repeated paragraph added.
7. Version 0.101.180, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A page with the same 12 word paragraph twice in a row gives one warning that names the page and counts 1 place; the build still passes.
- A 3 word line written twice, the same paragraph with another paragraph between, the same text in two list items, two headings or two table cells, and a repeat inside `pre` or `code` pass with no message from this check.
