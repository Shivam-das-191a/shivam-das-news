## Goal
The build stops when a link has an empty address, a `javascript:`, `vbscript:` or `file:` address, a `mailto:` with no e-mail address or a `tel:` with no number; it warns on `href="#"`, `http://` links, bare `www` addresses and links to localhost.

## Why it matters
A `javascript:` link runs code from the page text, an empty or `#` link goes nowhere, and a bare `www.example.org` is read by the browser as a page of this site and gives a 404. A post written by the owner can bring a link typed by hand.

## Steps
1. New `site/scripts/href-check-lib.mjs` with `checkHrefs(html, ownHosts)`.
2. `site/scripts/validate-html.mjs`: run it on every built page with the same own-host list as the picture check.
3. New test `href-check.test.ts` (32 cases, with a fake dist folder run of the real gate and a read of the real layout).
4. Run the whole test suite and the real build, then the gate on throw away copies of the real build with a bad link added.
5. Version 0.101.123, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- An empty href and a `javascript:` link fail the gate.
- `href="#"`, `http://`, a bare `www` address and localhost only warn.
