## Goal
The build warns when the text of a built page has a colon glued to the capital word that follows it (`Note:Read`, `He said:Then`), and never stops the build for it.

## Why it matters
Text pasted from Word or imported from Blogger often loses the space after a colon. A reader sees each one at once and trusts the site a little less. The punctuation check of v0.101.170 reads a missing space after a comma or semicolon only; nothing read the colon.

## Steps
1. New `site/scripts/colon-check-lib.mjs` with `checkColonSpacing(html)` (reads the title and the body text of every page; only the letters A to Z are read; an inline tag leaves no gap, a block tag, a `br` and a character reference end the run; comments and script, style, template, textarea, pre, code, kbd, samp, svg, noscript and select blocks skipped; attributes and the meta description not read; one message per page with a count; no errors).
2. The slip: a word of 2 or more letters, then `:`, then at once a word that starts with a capital letter and has 2 or more small letters after it.
3. Left out: the scheme of an address (`https:`, `mailto:` and the like), a word after a dot, a slash, an at sign or an underscore, a time or a ratio, a smiley, a single letter, a word after the colon with one small letter, code, text in another script.
4. `site/scripts/validate-html.mjs`: import it, run it on every built page, name it in the first comment line.
5. New test `colon-check.test.ts` (64 cases, with a fake dist folder run of the real gate).
6. Run the whole test suite and the real build, then the gate on a throw away copy of the real build with slips added.
7. Version 0.101.176, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A page with `Note:Read` and `He said:Then` gives one warning that names the page and counts 2 places; the build still passes.
- Clean colons, `5:30`, `https:`, a smiley, a single letter before the colon, text in `pre` or `code` and text in another script pass with no message.
