1. Copy the owner's file to `site/brand/source-icon.png` (1254 by 1254).
2. Run `npm run icons`: it writes the favicon files, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` and `badge-96.png`.
3. Make `og-default.png` (1200 by 630): the logo at 630 by 630 in the middle, on the logo's own corner colour.
4. Nothing else is changed: `config/site.json` already points to `/icon-512.png` and `/og-default.png`.
