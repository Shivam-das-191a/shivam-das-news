## Goal
The build stops when a `media` attribute of a link, picture source, style block or theme-colour tag holds a media query a browser cannot read; it warns on a media type that matches nothing and on a min-width larger than the max-width.

## Why it matters
A browser treats an unreadable media query as "not all": the style sheet is never applied, the picture source is skipped, the dark theme colour never shows, and nobody is told. `picture-check-lib.mjs` reads only an empty `<source media>`; nothing read the query itself.

## Steps
1. New `site/scripts/media-query-check-lib.mjs` with `checkMediaQueries(html)` (comments, script and template blocks skipped; the text of a style block not read; the range syntax left alone).
2. `site/scripts/validate-html.mjs`: import it, run it on every built page, name it in the first comment line.
3. New test `media-query-check.test.ts` (49 cases, with a fake dist folder run of the real gate).
4. Run the whole test suite and the real build, then the gate on a throw away copy of the real build with bad queries added.
5. Version 0.101.164, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A link with `media="(min-width:600)"` fails the gate and names the page; `media="tv"` is a warning only.
- `(min-width: 600px)`, `(prefers-color-scheme: dark)`, `(width >= 600px)` and an empty media pass with no message.
