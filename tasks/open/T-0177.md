## Goal
The build warns when the body text of a built page has a long run of words in capital letters (`BREAKING NEWS THE CITY COUNCIL HAS VOTED ...`), and never stops the build for it.

## Why it matters
Text pasted from a chat, an old notice or a social post is sometimes typed in capitals for a whole sentence. A reader takes it for shouting and trusts the site a little less. The title and heading check of v0.101.85 reads only the title and the headings; nothing read the body text.

## Steps
1. New `site/scripts/allcaps-check-lib.mjs` with `checkAllCapsRuns(html)` (reads the body text of every page; the title and the h1 to h3 blocks are left to the older check; an inline tag leaves no gap, a block tag, a `br` and a character reference end a run; comments and script, style, template, textarea, pre, code, kbd, samp, svg, noscript and select blocks skipped; attributes and the meta description not read; one message per page with a count and the first four words; no errors).
2. The slip: 10 or more words in a row written in capital letters (A to Z), at least 8 of them with 2 or more letters; the words `A` and `I` may sit inside the run; marks round a word are not part of it.
3. Left out: a run of 9 words or fewer, a run that is mostly one letter words, a word with a digit, a small letter, an apostrophe, a hyphen or a dot inside (it ends the run), code, text in another script.
4. `site/scripts/validate-html.mjs`: import it, run it on every built page, name it in the first comment line.
5. New test `allcaps-check.test.ts` (66 cases, with a fake dist folder run of the real gate).
6. Run the whole test suite and the real build, then the gate on a throw away copy of the real build with a long run added.
7. Version 0.101.179, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A page with a paragraph of 11 words in capitals gives one warning that names the page and counts 1 place; the build still passes.
- A run of 9 words, `UNITED STATES OF AMERICA`, `NASA`, `U.S.`, text in `pre` or `code`, a run in the title or a heading (left to the older check) and text in another script pass with no message from this check.
