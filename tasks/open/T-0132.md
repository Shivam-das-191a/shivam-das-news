## Goal
The build stops when a built page has a link inside a link, a button inside a button or a form inside a form; it warns on a button inside a link, a link inside a button and a field (input, select, textarea) inside a link or a button.

## Why it matters
HTML does not allow these. The browser repairs them in its own way: it closes the first link early, so the page shows two broken links, or it drops the inner form tag, so the inner fields are sent with the outer form. A control inside a link or a button also puts two controls in one place for the Tab key and a screen reader. A post written by hand (PLAN 37) or an old Blogger post (PLAN 11) can wrap a button in a link, and the owner cannot see the fault on the page.
