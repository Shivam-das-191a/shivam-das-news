## Goal
The build stops when a link (a with href), a button or an input that acts as a button on a built page has no name: no text, no picture alt, no svg title, no aria-label and no aria-labelledby to an element of the page.

## Why it matters
POLISH (Accessibility) asks for pages that work with a screen reader. A link or a button that shows only an icon has no name for a screen reader, so the reader hears "link" or "button" and nothing else. The site does it right today (382 links and 90 buttons on 17 built pages, all named), but nothing kept it that way when someone adds an icon link.

## Steps
1. New `link-names-lib.mjs` with `checkLinkNames`.
2. `validate-html.mjs`: call it for every built page.
3. New test `link-names.test.ts`.
4. Look at the real built pages first (all 382 links and 90 buttons of today's build), then run deliberate mistakes, one at a time.
5. Version 0.101.108, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.`
- A link with no text, an icon only link, an empty aria-label, an aria-labelledby to a missing id, a hidden text only, a button with no name and an input button with no value each fail the gate; good links and buttons pass; a vague text such as "click here" only warns.
