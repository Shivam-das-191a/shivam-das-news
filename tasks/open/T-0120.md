## Goal
The build stops when a video or audio plays by itself with sound, has no controls (a silent looping video is allowed) or loads over `http://`; it warns when a video has no captions track, no poster or no size, or a media element has no preload.

## Why it matters
Sound that starts alone covers a screen reader's voice, a player with no controls cannot be stopped from the keyboard, and people who cannot hear need captions. The site allows audio and video from its own files in a post (PLAN 37), so the check must exist before the first one.

## Steps
1. New `site/scripts/media-check-lib.mjs` with `checkMedia(html)`.
2. `site/scripts/validate-html.mjs`: run it on every built page.
3. New test `media-check.test.ts` (38 cases, with a fake dist folder run of the real gate and a read of the real layout).
4. Run the whole test suite and the real build, then the gate on throw away copies of the real build with a video added.
5. Version 0.101.122, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- Autoplay with sound, no controls and an `http://` source fail the gate.
- No captions, no preload, no poster and no size only warn.
