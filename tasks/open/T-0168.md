## Goal
The build warns when the text of a built page has a space before a comma or full stop, repeated commas or dots, or no space after a comma, and never stops the build for them.

## Why it matters
Text typed fast, pasted from Word or imported from Blogger often has "the vote , which", two commas in a row, two dots instead of three, or "said,then". A reader sees each one at once and trusts the site a little less. Nothing in the build read the punctuation of the text.

## Steps
1. New `site/scripts/punct-check-lib.mjs` with `checkPunctuation(html)` (reads the title and the body text; an inline tag leaves no gap, a block tag and a character reference end the run; comments and script, style, template, textarea, pre, code, kbd, samp, svg, noscript and select blocks skipped; attributes and the meta description not read; one message per kind with a count; no errors).
2. Kinds: a space before `, . ; : ! ?` that follows a letter, a digit, a closing bracket or a closing quote; repeated punctuation (two or more `,` `;` `:` in a row, exactly two dots, four or more dots); no space after a comma or semicolon between two words of 2 or more letters.
3. Left out: an ellipsis of three dots (with or without spaces), `&nbsp;` before a mark (French style), numbers with a comma, times, web addresses and abbreviations, a comma next to a digit or a single letter, a mark followed by another mark (`:)`, `?!`), code.
4. `site/scripts/validate-html.mjs`: import it, run it on every built page, name it in the first comment line.
5. New test `punct-check.test.ts` (70 cases, with a fake dist folder run of the real gate).
6. Run the whole test suite and the real build, then the gate on a throw away copy of the real build with the three slips added.
7. Version 0.101.170, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A page with `The vote , which ended late,, said,then left..` gives three warnings that name the page; the build still passes.
- `Wait ... what`, `1,000`, `5:30`, `e.g.`, `:)`, `?!`, `&nbsp;:`, `<b>word</b>,` and text in `pre` or `code` pass with no message.
