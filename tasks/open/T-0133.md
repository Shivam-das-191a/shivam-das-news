## Goal
The build stops when the text of a built page holds a common reference escaped twice (`&amp;amp;`, `&amp;nbsp;`, `&amp;#8217;`) or a numeric reference that is empty, is 0, is in the surrogate range or is above 10FFFF; it warns on a common name with no semicolon (`&nbsp`, `&mdash`) and on a reference to a control character or an old Windows code (`&#146;`).

## Why it matters
An ampersand escaped twice shows the reader the code `&amp;` inside a headline or a sentence. A numeric reference to a character that does not exist shows a question mark box. A name with no semicolon can show as plain text, and an old Windows code such as `&#146;` is only repaired by the browser. A post written by hand (PLAN 37) or an old Blogger post (PLAN 11) can carry these, and the owner cannot see it in the dashboard preview.
