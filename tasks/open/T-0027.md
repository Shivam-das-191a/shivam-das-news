## Goal
The owner opens one table of all pictures without alt text, types a short sentence for each, and saves them all in one commit to `config/media.json`.

## Why it matters
Writing alt text one picture at a time on the Files screen is slow. The plan (PLAN 33.3) asks for one screen for all missing alt text.

## Steps
1. Read `NEWS_WEBSITE_PLAN.md` 33.3 and the rules of Part 7a.
2. Add `mergeAltBulk` to `media-meta.js` (all or nothing, never removes an alt text).
3. Write `bulk-alt.js` on top of it; wire the route `#/files/alt`, `bulkAltView` and the link in `app.js`; Save checks the role and the limits again and writes with the file sha.
4. Write the jsdom tests, make deliberate mistakes, run the whole suite and the build.
5. Bump the version, write the changelog, update `CODING_PLAN.md` and `INCOMPLETE.md` (`VERSIONING.md`).

## Done when
- `npm test`, `npm run build` and `npm run preflight` pass; older tests pass unchanged.
- In a jsdom test: the table lists only files without alt text; Save all sends only the filled rows in one call; a red error saves nothing; a failed save keeps the typed text; a read-only role cannot save; the route, the link and the role check are in `app.js`.
