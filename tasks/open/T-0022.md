## Goal
The Settings screen shows the Search engine listing box of the home page (preview, home title, site description), and the home page head uses the home title when it is set.

## Why it matters
The home page is the most visited page. Its title was fixed to "site name - tagline" and could not be changed; now the owner can set it and see how it looks in Google.

## Steps
1. Read `NEWS_WEBSITE_PLAN.md` 33.2 and the code of Parts 6a and 6b.
2. Add `homeHead` to `seo.ts` and use it in `index.astro`.
3. Let `entryListing` take an automatic title from the screen (`ctx.autoTitle`) and `entryBox` take its own help texts (`hints`).
4. Draw the box in Settings (the description field moves into it), save `homeTitle` (removed when empty), stop on the red errors.
5. Write the tests, make deliberate mistakes, build once with a real value.
6. Bump the version, write the changelog, update `CODING_PLAN.md` and `INCOMPLETE.md` (`VERSIONING.md`).

## Done when
- `npm test`, `npm run build` and `npm run preflight` pass; older tests pass unchanged.
- With no `homeTitle` the home page head is exactly as before; with one it is the typed text.
