## Goal
`site/public/admin/js/hosted-meta.js` holds the pure rules of PLAN 34.5 and 34.6: the automatic alt text (marked for review), `width`, `height`, `loading`, `fetchpriority` and the srcset widths, the agency host list with the "needs confirm" rule, the rights notice, and the row written to `config/media.json` for a hosted file.

## Why it matters
Part 3 (the Save pipeline) needs these rules, and Part 3 waits for the owner's decisions 15 and 16. These rules need no decision, so they are done first and tested alone. Nothing calls the file yet, so the live site and the dashboard do not change.

## Steps
1. Read `NEWS_WEBSITE_PLAN.md` 34.5 and 34.6, `LOGICS.md` 22, `media-meta.js` (`mergeMedia`, `mediaErrors`, `ALT_WARN`).
2. Write `hosted-meta.js`: `autoAlt`, `imgAttributes`, `isAgencyHost`, `needsConfirm`, `sourceHostOf`, `RIGHTS_NOTICE`, `recordHosted`, `autoAltFiles`.
3. Write `site/tests/unit/hosted-meta.test.ts`.
4. Make deliberate mistakes and see the tests fail; restore the code.
5. Bump the version, write the changelog, update `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test`, `npm run build` and `npm run preflight` pass; older tests pass unchanged.
- The writer's alt text is kept; an empty one is filled from the caption, the heading or the post title, cleaned, cut to 125 characters and marked auto; with no text nothing is invented.
- `width` and `height` are always written, the first picture is `fetchpriority="high"`, the others `loading="lazy"`; the srcset widths follow the file width (edges tested).
- An agency or stock host (and its sub names) is held until the writer confirms; a host that only ends the same way is not held.
- `recordHosted` writes the row of PLAN 34.6 through `mergeMedia` and refuses a bad address, hash, size, time or field.

## Evidence
- Tests: before this change `Test Files 140 passed (140), Tests 2734 passed (2734)`; after it `Test Files 141 passed (141), Tests 2768 passed (2768)`; 34 new tests in `hosted-meta.test.ts`.
