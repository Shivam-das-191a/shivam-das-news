## Goal
When the owner saves a post with picture hosting on, the dashboard reads `quality` from `site/config/images.json` and the new pictures use it.

## Why it matters
Part 7i added the setting, 7h made the picture steps accept it, 7j added the reader and the pass-through. This part connects the Save, so the number finally has an effect.

## Steps
1. `hosting-hook.js`: read the quality with `readImagesQuality` when hosting is on and no quality was given; pass it to `startHostingSave`.
2. `hosting-save.js`: pass `quality` to `hostingSetup`.
3. `hosting-quality-save.test.ts` (13 tests); then five deliberate mistakes.
4. Bump the version, write the changelog, update `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.`
- A good number in the file reaches the picture step; a missing file, a GitHub error or a bad number leaves every call exactly as before; hosting off never reads the file.
