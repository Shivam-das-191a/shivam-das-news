## Goal
The build stops when the head of a built page is broken in a way that hurts search or sharing: no title, an empty title, a canonical that is not a full address or that is there twice, a robots tag that says index and noindex, no og:title, an og:url or og:image that is not a full address.

## Why it matters
POLISH (Final Pre-launch Sweep) and PLAN 5 and 6 need a title, one canonical and share tags on every page. Until now the build checked the canonical only for being there and the description only for being there; a missing title, a relative canonical, two canonicals or a self-contradicting robots tag passed every check. Google ignores or mis-reads such pages, and a shared link would show no title.

## Steps
1. New `head-check-lib.mjs` with `checkHead(html)` and `checkDuplicateTitles(list)`.
2. `validate-html.mjs`: run `checkHead` on every built page and `checkDuplicateTitles` once at the end.
3. The fake pages of the eleven older gate tests get a title (one inserted tag each), because a page with no title is now an error.
4. New test `head-check.test.ts` (43 cases, with a fake dist folder run of the real gate).
5. Run the gate on today's real build, then on a throw away copy with the real build broken in three ways, then put deliberate mistakes into the library one at a time.
6. Version 0.101.114, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A page with no title, an empty title, a relative canonical, two canonicals, two robots tags, index plus noindex, no og:title, or a relative og:url or og:image fails the gate.
- A title over 70 characters, a description over 160 characters or empty, a canonical on http, og:url that is not the canonical, no og:image, no twitter:card, no theme-color and indexable pages with one shared title only warn.

## Evidence
- Files changed: the paths of this card (new files: the library, the test and this card). The eleven older tests changed by one inserted `<title>` in the fake page.
- Check: `npm test`: 202 files and 4415 tests passed (before: 201 and 4372). `npm run build` ended with `Validation passed.` on today's real build with no new message (17 pages, every title different, every page with a title, one canonical and share tags).
