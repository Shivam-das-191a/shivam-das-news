## Goal
The dashboard's GitHub token can reach only this public repository, not the owner's private ones.

## Why it matters
`workers/auth/wrangler.toml` asks GitHub for the `repo` scope, which reaches every repository of the account, private ones included. `public_repo` is enough while this repository is public.

## Steps
1. Owner: confirm the repository is public (decision 17).
2. Set `GITHUB_SCOPE = "public_repo"` in `workers/auth/wrangler.toml`.
3. In `workers/auth` run `npx wrangler deploy`.
4. Sign out of the dashboard and sign in again; accept the new, smaller permission.
5. Save a test change in Settings to confirm saving still works, then revert it.

## Done when
- The GitHub permission screen lists public repository access only.
- The dashboard still saves.

## Evidence
(The deploy output line, a note of what the GitHub screen said, the saved change.)

## If it goes wrong
Set the value back to `repo` and redeploy.

## Stop and ask the owner if
- The repository is private (then `repo` is needed and this task is closed).
