## Goal
The list of pictures that `hosting-screen.js` draws (`.hosting-result`, `.hosting-list`, `.hosting-row`, the four tones and the buttons) gets its own style in `site/public/admin/admin.css`, in light and dark.

## Why it matters
Until now the list showed without a style. A writer must see at once which picture is hosted, which needs a click and which failed.

## Steps
1. Read `hosting-screen.js` (the classes it draws) and `TONES` in `hosting-result.js`.
2. Add one marked block at the end of `admin.css`: box, list, row, one rule for each tone, button row, narrow screen rule, the `hidden` rule last.
3. Use only the colour variables of `:root` (no fixed colour), so dark mode follows the page.
4. Write `site/tests/unit/admin-hosting-style.test.ts` (8 tests, includes a 4.5:1 contrast check in light and dark).
5. Make deliberate mistakes in `admin.css` and see the tests fail.
6. Bump the version, write the changelog, update `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes (all older tests unchanged).
- Every class of the screen and every tone has a rule; no fixed colour; the `hidden` attribute still hides; labels keep 4.5:1.
- No JavaScript, Worker or config changed, so the live site and the dashboard work as before.
