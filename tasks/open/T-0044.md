## Goal
`site/public/admin/js/hosting-client.js` has `makeFetchPictures({ endpoint, token, fetch, timeoutMs })` and `imagesUrl(endpoint)`: the `fetchPictures(urls)` function that `hostPost` asks for. It sends `POST <endpoint>/fetch` with the GitHub token of the signed-in user and turns every failure into a reason word with a plain sentence. `hosting-run.js` gets four new reason words (`sign_in`, `not_allowed`, `rate_limited`, `worker_off`).

## Why it matters
Without this the hosting run cannot reach the Worker. Without the new reason words every failure of the service would show the same general sentence and the writer would not know whether to sign in again, wait or ask the owner. Nothing calls it yet, so the live site and the dashboard do not change.

## Steps
1. Read `workers/images/index.js` (who may call, the answers 200, 400, 401, 403, 413, 429, 503), `hosting-run.js` (`download`, `REASONS`).
2. Write `hosting-client.js`: `imagesUrl`, `makeFetchPictures`, `MAX_URLS`.
3. Add the four reason words to `REASONS` in `hosting-run.js`.
4. Write `site/tests/unit/hosting-client.test.ts`: the request, refusals before any request, every status, and the real Worker code behind a fake network together with `hostPost`.
5. Make deliberate mistakes and see the tests fail; fix the gaps.
6. Bump the version, write the changelog, update `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test`, `npm run build` and `npm run preflight` pass; older tests pass unchanged.
- The request is a POST to `<origin>/fetch` with the Bearer token, JSON, `credentials: omit`, no referrer, no cache and a time limit; a bad list, a bad address or a bad token shape stops before any request.
- 401, 403, 413, 429, 503, other statuses, a broken answer, no network and a timeout each give their reason word and sentence; the token is in no answer.
- With the real Worker code: an allowed login hosts the pictures; a login that is not allowed, an unknown token, the kill switch and the rate limit each fail only the pictures concerned and leave the post as it was.
