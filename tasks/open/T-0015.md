## Goal
The post editor shows a "Search engine listing" box: a Google preview with a Mobile and Desktop switch, an Edit link that opens the three fields (page title, meta description, URL handle) with counters, an "auto" label and "Reset to auto". Saving works exactly as before.

## Why it matters
The owner can fix the search listing of a post without knowing any code, and sees what Google will show while typing.

## Steps
1. Read `NEWS_WEBSITE_PLAN.md` 33.2 and `LOGICS.md` Section 21; use the rules of `listing.js`.
2. Write `site/public/admin/js/listing-box.js` (the box wraps the editor's own three inputs; every text is a text node).
3. Wire it into `editorView` in `site/public/admin/js/app.js`; remove the old Google card and the old description counter; add the styles.
4. Write `site/tests/unit/admin-listing-box.test.ts` (pure helper, box in jsdom, box in the real editor).
5. Bump the version, write the changelog, tick Part 2 in `CODING_PLAN.md`, update `INCOMPLETE.md` (`VERSIONING.md`).

## Done when
- `npm test`, `npm run build` and `npm run preflight` pass; the four older editor tests pass unchanged.
- A new post shows the box open, an existing post shows it closed; typing updates the preview and the counters at once.
- Counters change colour at 61, 71 (title) and 161, 321 (description); Reset to auto restores the automatic value.
- Nothing is saved differently: the Markdown a save writes is the same as before.
