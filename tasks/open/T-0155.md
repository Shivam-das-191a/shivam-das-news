## Goal
The build stops when a page has an `on...` attribute that is a typo of a real event (`onclik`) or handler code that is not valid JavaScript (a bracket, a brace or a quote never closed); it warns on an empty handler and on code that starts with `javascript:`.

## Why it matters
An attribute written `onclik` is not an event, so the browser keeps it as plain text and nothing ever runs; code with a missing bracket never runs either. The reader sees a button that does nothing, and no message reaches the owner. A snippet pasted by hand (PLAN 37) or an old Blogger post can carry these. Until now nothing read event attributes.
