## Goal
The build stops when a built page has a picture with no alt attribute or an `http://` picture, and warns about a picture from another website or without width and height.

## Why it matters
POLISH lists alt text on all content images, width and height on images, and no picture from another website. Until now only the post files were checked, not the built page the reader gets.

## Steps
1. New `img-check-lib.mjs` with `checkImgTags`, `attrOf`, `hostOf`, `ownHostsOf`.
2. `validate-html.mjs`: call `checkImgTags` for every built page with the host of `SITE_URL` as our own.
3. New test `img-check.test.ts`.
4. Deliberate mistakes, one at a time.
5. Version 0.101.101, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.`
- A built page with a picture that has no alt attribute, or an `http://` picture, fails the gate; a picture from another website or without width and height only prints a warning; an empty `alt=""` and our own full address do not complain.

## Evidence
- Files changed: the paths of this card (new files: the library, the test and this card).
- Check: `npm run preflight` ended with `PREFLIGHT PASS (warnings: budgets)`: tests 190 files and 4018 passed (before: 189 files and 3997), build pass with the new gate (`Validation passed.`), content pass, tasks pass (98 cards). The budget warning is the old one (CHANGELOG, INCOMPLETE; decision 43).
- Deliberate mistakes: seven made one at a time (no alt check, http only a warning, own host test inverted, width and height `and` instead of `or`, no skip of script and template, the gate ignoring errors, the gate with no own hosts). Six were caught at once; the seventh was NOT caught, so one test was added (a full address of our own website must not warn) and the mistake was caught after that. The files were put back after each and the tests passed again.
- Not verified live: no GitHub run of the validate workflow yet.

## If it goes wrong
Put back `validate-html.mjs` of v0.101.100 and delete the library and the test. The gate then checks pictures only in the post files, as before.
