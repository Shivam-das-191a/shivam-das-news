## Goal
The build stops when a page or the style stops a reader from zooming (pinch zoom or enlarging the page), so nobody can block it by mistake later.

## Why it matters
Readers with weak eyesight must be able to zoom (WCAG 1.4.4). One wrong word in the viewport tag, or one `touch-action` rule on the whole page, turns zoom off on every phone. Until now the build only checked that the viewport tag exists (v0.101.104).

## Steps
1. New `site/scripts/zoom-check-lib.mjs` with `checkZoomHtml(html)` and `checkZoomCss(css)`.
2. `site/scripts/validate-html.mjs`: run the page check on every built page and the style check once on all built style.
3. New test `zoom-check.test.ts` (41 cases, with a fake dist folder run of the real gate and a read of the real template and style).
4. Run the gate on today's real build, then on throw away copies with the real build broken.
5. Version 0.101.117, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- `user-scalable=no`, a `maximum-scale` under 2, and `touch-action: none` on html, body, :root, main or `*` fail the gate.
- A `maximum-scale` from 2 up to 5 only warns.

## Evidence
- Files changed: the paths of this card (new files: the library, the test and this card). Nothing in `site/src/` or `site/content/` changed.
- Check: `npm test`: 205 files and 4543 tests passed (before: 204 and 4502). `npm run build` ended with `Validation passed.` on today's real build with no new message (with `SITE_URL` set).
- Throw away copies of the real build in `/tmp` (not in the ZIP): `user-scalable=no` put in the viewport of `dist/index.html`: exit code 1 and the line `dist/index.html: the viewport has user-scalable=no, so a reader cannot pinch to zoom (WCAG 1.4.4)`. `body{touch-action:none}` put in the head of `dist/404.html`: exit code 1 and the line `dist: the rule "body" sets touch-action to none, which turns off pinch zoom for the whole page`.
- Not proved: a real phone; the check reads the tag and the style text.
