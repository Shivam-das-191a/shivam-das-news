## Goal
The build stops when the `integrity` attribute of a script or style sheet is not a real fingerprint or sits on a file from another website with no `crossorigin`; it warns on an empty integrity, one on a tag that does not read it, and a library-host script or style sheet with none.

## Why it matters
A browser ignores a mistyped fingerprint with no message, so the page is unprotected while the owner believes it is safe. A fingerprint on a file from another website with no `crossorigin` makes the browser block the file, so the page loses its look or function. Nothing in the build read the attribute.

1. New `site/scripts/integrity-check-lib.mjs` with `checkIntegrity(html, ownHosts)` (comments and template blocks skipped; ad, analytics and Turnstile hosts left alone).

## Done when
