## Goal
The build stops when a page has a role that is not real, an `aria-` name that does not exist, a wrong value for an `aria-` attribute with a fixed list, `aria-hidden="true"` on `body` or `html`, or `aria-hidden="true"` on something the Tab key reaches; it warns on an empty `aria-label`, `aria-hidden` around a link inside, `role="presentation"` on something the Tab key reaches and a role the tag already has.

## Why it matters
A link hidden from a screen reader but still reached by the Tab key is a trap for a blind reader. A typo in an `aria-` name or a role is ignored silently, so the page looks fine and does not work. A post written by the owner can bring hand typed HTML.

1. New `site/scripts/aria-check-lib.mjs` with `checkAria(html)`.
2. `site/scripts/validate-html.mjs`: import it and run it on every built page.
