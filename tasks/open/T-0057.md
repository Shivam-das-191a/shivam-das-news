## Goal
The smaller WebP copies of each new picture are saved in the same ONE commit as the picture, the post and `config/media.json`, and the media row of the picture notes which widths exist (`variants: [480, 800, ...]`). It is off unless the optional dep `makeVariants` is given, and the dashboard does not give it yet.

## Why it matters
The page part (4c-5) writes `srcset` from the media row. A `srcset` must never name a copy that is not on the site, so a copy and its note must be saved together or not at all.

## Steps
1. Read PLAN 34.5 and 34.6, `hosting-commit.js`, `hosting-pipeline.js`, `hosting-optimize.js` (`makeVariants`) and `hosting-srcset.js` (`variantsFor`).
2. New `hosting-copies.js`: `addCopiesToRun(run, makeVariants)` adds each copy right after its picture as a file `{ src, path, bytes, variant }` and writes `variants` in the media row. It never throws. One wrong copy means no copy for that picture; the picture itself is still saved.
3. `hosting-commit.js`: a file with `variant` is a copy. It is not counted as a picture (`counts.copies`), and the commit is refused when a copy is not noted in the media row, or a noted width has no copy in the commit, or a copy has no picture, a bad width or a wrong name.
4. `hosting-pipeline.js`: the optional dep `makeVariants`; a preview never makes copies; the answer has a new key `copies`; a failed copy adds one plain sentence to the message.
5. Write `hosting-copies.test.ts` (34 tests); relax the import guard in `hosting-srcset.test.ts` and `hosting-variants.test.ts`.
6. Make deliberate mistakes and see the tests fail.
7. Bump the version, write the changelog, update `NEWS_WEBSITE_PLAN.md` 34.6, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes (all older tests unchanged except the two import guards named in step 5).
- A save with `makeVariants` makes ONE commit: picture, its copies, post, media file; the media row has `variants`.
- A save without `makeVariants` is exactly as before (3 files for one picture, `copies` is `[]`).
- A copy without its note, or a note without its copy, stops the commit with a plain sentence.
- `hosting-setup.js`, `hosting-save.js`, `hosting-hook.js`, `hosting-flow.js` and `app.js` do not name `makeVariants`, so copies stay off in the dashboard.
