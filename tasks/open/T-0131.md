## Goal
The build stops when a tag of a built page has the same attribute twice or is a tag HTML has dropped (marquee, blink, frame, frameset, applet and the like); it warns on an old presentation tag (center, font, big) and an old presentation attribute (align, bgcolor, valign).

## Why it matters
A browser keeps the first copy of a repeated attribute and silently ignores the rest, so `class="a" class="b"` shows only `a` and the style the writer meant is lost. A dropped tag such as `<marquee>` is not run as it was meant. A post written by hand (PLAN 37) or an old Blogger post (PLAN 11) can carry them, and the owner cannot see it on the page.
