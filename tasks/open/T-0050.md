## Goal
`site/public/admin/js/hosting-save.js` has `startHostingSave({ cfg, gh, next, body, orig, newPath, tree?, canEdit?, onResult?, dryRun?, fetch?, optimizeDeps? })`: it says whether Save should host the pictures of this post and, if so, gives the ready `hostingFlow`; with `makePostSerializer` the commit writes every field of the editor.

## Why it matters
The hook in `app.js` cannot be tested without a browser, so everything that can be decided by plain functions (off, archived, no pictures, a moved post, the fields of the saved file, the names already taken) is decided here and tested. A mistake in the file text would change a live post, so the serializer keeps every editor field. Nothing calls it yet, so the live site and the dashboard do not change.
