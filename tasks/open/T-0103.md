## Goal
The build stops when a font face has no `font-display` of swap, fallback or optional, when a font file or import comes from another website, or when a page links to a font website. More than four font faces only warns.

## Why it matters
POLISH (Speed) lists "Fonts self-hosted, `font-display: swap`, one or two weights". The site does it today (Fontsource files in `/_astro/`), but nothing kept it that way when someone adds a font.

## Steps
1. New `font-check-lib.mjs` with `checkFontCss` and `checkFontLinks`.
2. `validate-html.mjs`: check the links of every built page; check the collected style text when at least one page was built.
3. New test `font-check.test.ts`.
4. Deliberate mistakes, one at a time.
5. Version 0.101.106, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.`
- A face without font-display, a font file from another website, an import from a font website and a link to a font website each fail the gate; a good font passes; five faces only warn.

## Evidence
- Files changed: the paths of this card (new files: the library, the test and this card).
- Check: `npm test`: 195 files and 4126 tests passed (before: 194 and 4100). `npm run build` ended with `Validation passed.` on today's real build (4 faces: Lexend 600 and 800, Inter 400 and 600, all `font-display:swap`, all from `/_astro/`).
- Deliberate mistakes: seventeen made one at a time. Fourteen were caught at once; two were NOT (a face with no weight not counted as 400; the start of the host name not checked) and one could not be applied until the script was fixed (a property name only ending like another); a test was added for each and all seventeen are now caught.
- Not verified live: no GitHub run of the validate workflow yet.

## If it goes wrong
Put back `validate-html.mjs` of v0.101.105 and delete the library and the test.

## Stop and ask the owner if
- The cases in `AI_START_HERE.md` Section 4.
- A real build fails the new gate and the fix would be to weaken a rule.
