## Goal
`site/public/admin/js/hosting-commit.js` has `buildHostingCommit(run, o)` and `commitHosting(gh, run, o)`: the answer of `hostPost` (new pictures, new post, new `config/media.json`) becomes ONE commit through `commitFiles` of `github.js`, all or nothing.

## Why it matters
The live site must never have a post that points at a picture that is not there, and a picture must never be saved without its media row. One commit also means one deploy. Nothing calls it yet, so the live site and the dashboard do not change.

## Steps
1. Read `hosting-run.js` (what `hostPost` returns), `github.js` (`commitFiles`), `app.js` (how posts and `config/media.json` are written).
2. Write `hosting-commit.js`: `buildHostingCommit`, `commitHosting`.
3. Write `site/tests/unit/hosting-commit.test.ts`: the list and its order, the message, refusals, and the real `GitHub` client behind a fake network.
4. Make deliberate mistakes and see the tests fail; fix the gaps.
5. Bump the version, write the changelog, update `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test`, `npm run build` and `npm run preflight` pass; older tests pass unchanged.
- The pictures, the post and `config/media.json` go into one tree, one commit and one branch move; a run that changed nothing makes no commit and no request.
- A bad path, a picture outside the media folder, a path used twice, an empty picture or post, and a picture without its media row stop the run before any request, with a plain sentence.
- A failed upload does not move the branch; "someone else saved" shows the plain sentence and nothing is forced.

## Evidence
- Tests: see the changelog entry of 0.101.46 (before 144 files and 2841 tests, after 145 files and 2863 tests).
- Deliberate mistakes: eighteen; one gap (path length) closed, then all caught.
- Not verified live: not connected to anything; tested with a fake network, not against GitHub.

## If it goes wrong
Delete `hosting-commit.js` and its test and revert the version. Nothing else uses them.
