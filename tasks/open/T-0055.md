## Goal
The plain functions that decide the smaller copies of a hosted picture (PLAN 34.5: srcset 480, 800, 1200, 1600): the name of a copy, which widths need one, the planned size of each, the text of the `srcset` attribute, and how to tell a copy from a main picture in a list of paths. No file is made and no page changes.

## Why it matters
The next parts (making the copies in the browser, putting them in the ONE commit, hiding them on the Files screen, writing `srcset` on the page) all need the same few rules. Written and tested first, they cannot disagree with each other.

## Steps
1. Read PLAN 34.5, LOGICS 22 and `imgAttributes`, `SRCSET_WIDTHS` in `hosted-meta.js`, `isMediaPath` in `media-meta.js`, `seoName` in `hotlink.js`, `checkNewName` in `file-rename.js`.
2. Decide the copy name: a DOT and the width before the ending (`name.480w.webp`). A main name never holds a dot (`seoName` makes only a-z, 0-9 and hyphens; the rename check refuses a dot), so a main picture can never be taken for a copy.
3. Write `site/public/admin/js/hosting-srcset.js` (pure; imports only `hosted-meta.js` and `media-meta.js`).
4. Write `site/tests/unit/hosting-srcset.test.ts` (30 tests).
5. Make deliberate mistakes and see the tests fail.
6. Bump the version, write the changelog, update `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes (all older tests unchanged).
- Only a `.webp` under `/media/` that is not a copy can have copies; a GIF, JPEG or PNG gets none.
- A copy exists only for a width STRICTLY narrower than the picture; the `srcset` ends with the main file at its true width; a narrow picture gets no `srcset`.
- A name such as `a.0480w.webp` is not a copy; a copy whose main picture is missing is not hidden.
- No other file imports the new file yet.

## Evidence
- Tests: see the changelog entry of 0.101.58 (before 156 files and 3185 tests, after 157 files and 3215 tests, all passing).
- Deliberate mistakes: thirteen in `hosting-srcset.js`, all caught.
- Found by the first test run: a name with a leading zero (`a.0480w.webp`) was read as a copy of width 480. Fixed: a copy name must be exactly what `variantPath` makes.
- Not verified live: no page, no Worker and no file uses it.

## If it goes wrong
Delete `hosting-srcset.js` and `hosting-srcset.test.ts`; revert the version.
