## Goal
Deleting a picture from the Files screen also deletes its smaller copies (`name.480w.webp`, ...) and removes their notes, all in the same ONE commit. A picture with copies can be deleted again (the lock of 4c-4a is lifted for delete only).

## Why it matters
A copy left behind is a file that no page can reach and that the Files screen hides, so the owner could never find it. This part makes delete safe before copies are switched on. Rename and replace stay locked for a picture with copies.

## Steps
1. Read `file-delete.js` rules in this card, `hosting-srcset.js` (`variantsOnList`), `app.js` `onDelete` and `files-screen.js` `deleteBox`.
2. New `file-delete.js`: `planDelete(path, { sitePaths, pub })` (the picture first, then the copies that exist; throws a plain sentence for a path that is not a picture or is already gone) and `mapWithout(map, paths)`.
3. `app.js` `onDelete`: use `planDelete` for the commit list and `mapWithout` for `config/media.json`; the commit message names the copies. Role check, fresh read of the content and the use check stay as they were.
4. `files-screen.js`: the Delete box is no longer locked; the question and the answer name the copies; the hidden count goes down.
5. Write `file-delete.test.ts` and extend `admin-files-copies.test.ts`; update one source guard in `admin-file-delete.test.ts` and the import guard in `hosting-srcset.test.ts`.
6. Make deliberate mistakes and see the tests fail.
7. Bump the version, write the changelog, update `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.`
- A delete of a picture with two copies makes ONE commit: the picture, both copies and the changed `config/media.json`; the message says "and 2 smaller copies".
- A delete of a picture without copies is exactly as before.
- A picture that a post uses is still refused; the role check and the fresh read of the content still come first.
- A copy of another picture is never deleted.
- Rename and Replace of a picture with copies still show the plain sentence.
- `makeVariants` is named in no dashboard file that switches copies on.
