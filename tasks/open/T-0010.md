## Goal
The dashboard has a read-only **Tasks** screen that shows what waits for the owner, the decisions that block work, the board, and a Copy AI prompt button.

## Why it matters
The owner can see in one place what only the owner can do, and how long each step takes, without reading 140,000 words of documents.

## Steps
1. Write `site/public/admin/js/tasks.js` with pure functions (read a card, read the decision table, what a card waits for, the board, the owner list, the prompt).
2. Add the menu item, the route and `tasksView` to `site/public/admin/js/app.js`; add the action `tasks` for admin and editor in `roles.js`; add the board styles.
3. Write `site/tests/unit/admin-tasks.test.ts` (pure functions and the screen in jsdom, including a check that nothing is written to GitHub).
4. Bump the version, write the changelog, update `INCOMPLETE.md`, `CODING_PLAN.md` and `tasks/README.md` (`VERSIONING.md`).
