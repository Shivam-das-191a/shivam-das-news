## Goal
`workers/images/lib.js` downloads pictures by the rules of PLAN 34.3 and 34.8: every address and redirect checked, at most 3 redirects, 10 MB, 5 seconds idle, 15 seconds in all, the real bytes checked, SVG refused, a list of at most 30 with 4 at a time. `fetch` and the host name lookup are passed in, so it is tested with fake sites.

## Why it matters
Part 2 of Phase 3c is the Worker. It is cut in two: this part is the code that does the work and can be tested completely; Part 2b adds the entry point, the sign-in, the rate limit and `wrangler.toml`. Nothing here can be called, because there is no `index.js`, no route and no deploy, so the live site is unchanged.

## Steps
1. Read `NEWS_WEBSITE_PLAN.md` 34.3 and 34.8, `LOGICS.md` 22, `hotlink.js` (T-0036), `media-meta.js` (`pictureKind`), `workers/trap/lib.js` for the style.
2. Write `workers/images/lib.js`: `fetchPicture`, `fetchPictures`, `resolveViaDoh`, `allPublic`. Reuse `checkAddress`, `checkRedirects` and `pictureKind`; do not copy them.
3. Write `site/tests/unit/images-lib.test.ts` with fake sites for every rule of LOGICS 22 that is about the download.
4. Make deliberate mistakes and see the tests fail; restore the code.
5. Bump the version, write the changelog, update `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test`, `npm run build` and `npm run preflight` pass; older tests pass unchanged.
- A private address, http, a port, a user name, a fourth redirect, a redirect to a private address, a name that resolves to a private address, a body over 10 MB, an idle or slow download, an SVG and a text file named `.jpg` are all refused with a reason word.
- A 403 is retried once without the referrer; no fake referrer, cookie or agent is ever sent.
- 30 pictures are accepted, 31 refused; at most 4 downloads run at once; a repeated address is fetched once.
