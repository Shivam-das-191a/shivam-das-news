## Goal
The build warns when the text of a built page holds a broken character: the replacement mark (U+FFFD), text saved in one encoding and read in another (a curly apostrophe shown as three odd letters), or a hidden control character (U+0080 to U+009F). It never stops the build for them.

## Why it matters
A post imported from Blogger, pasted from Word or saved in the wrong encoding often shows `It` plus three odd letters plus `s`, or a black diamond with a question mark. A reader sees it at once, and Google News and Discover read it as a careless site. Nothing in the build read the text for it.

## Steps
1. New `site/scripts/garble-check-lib.mjs` with `checkGarbledText(html)` (reads the title and the body text; tags and attributes are not read; comments and script, style, template, textarea, pre, code, kbd, samp, svg and noscript blocks are skipped; one message per kind with a count; no errors; every character is written as a `\u` escape so the file stays ASCII).
2. Kinds: the replacement mark (a run is one place); a lead letter (a-circumflex, A-tilde, A-circumflex) followed by a symbol of the Windows-1252 table; a control character U+0080 to U+009F (a run is one place; one inside a mojibake pair is not counted twice).
3. `site/scripts/validate-html.mjs`: import it, run it on every built page, name it in the first comment line.
4. New test `garble-check.test.ts` (57 cases, with a fake dist folder run of the real gate).
5. Run the whole test suite and the real build, then the gate on a throw away copy of the real build with a broken text added.
6. Version 0.101.169, changelog, `CODING_PLAN.md`, `INCOMPLETE.md`, `UPDATE_NOTE.md`.

## Done when
- `npm test` passes and `npm run build` ends with `Validation passed.` and no new message.
- A page with a curly apostrophe turned into three odd letters, and one with a replacement mark, give a warning each that names the page; the build still passes.
- Real curly quotes, real accented letters (e-acute, n-tilde, Romanian a-circumflex, Portuguese capital A-tilde in a word), `&nbsp;`, zero width characters, text in other scripts, and text in `pre` or `code` pass with no message.
