## Goal
`site/public/admin/js/hotlink.js` holds the pure rules of PLAN 34 and LOGICS 22: find outside pictures, check an address and its redirects, make the SEO file name, choose the path from the post date, and look up a picture that is already hosted. No network, no screen.

## Why it matters
Phase 3b is complete, so Phase 3c (pictures from other websites become our own files) is the next phase. Part 1 is the part with the most rules and no risk: nothing calls it yet, so the live site and the dashboard do not change.

## Steps
1. Read `NEWS_WEBSITE_PLAN.md` 34.3 to 34.6, `LOGICS.md` 22, `import-images.js`, `media-meta.js` (`readableName`), `slug.js`.
2. Write `hotlink.js`: `findExternal`, `isOwnHost`, `checkAddress`, `checkRedirects`, `seoName`, `datePart`, `hostedPath`, `findHosted`.
3. Write `site/tests/unit/hotlink.test.ts` for every rule of the LOGICS 22 list that needs no network.
4. Make deliberate mistakes in the code and see the tests fail; restore the code.
5. Bump the version, write the changelog, update `CODING_PLAN.md`, `INCOMPLETE.md` and `UPDATE_NOTE.md` (`VERSIONING.md`).

## Done when
- `npm test`, `npm run build` and `npm run preflight` pass; older tests pass unchanged.
- Every outside picture place is found (front matter `image` and `ogImage`, Markdown, `<img src>`, `<img srcset>`); our own host, relative and `data:` addresses and code samples are skipped.
- Every refused address of LOGICS 22 is refused with a reason word (http, port, user name, localhost, `.local`, `.internal`, private, loopback, link-local and IPv6 forms, a fourth redirect, a redirect to a private address).
- The name follows PLAN 34.4 (order, 3 to 6 words, 60 characters, no camera name, no other site name, `-2` and `-3`); the path uses the post date.
