# CODING_PLAN.md: Build Plan Step by Step

## 1. Tech
Astro + TypeScript, Tailwind, Markdown content collections, Pagefind, Decap CMS (or custom admin), Cloudflare Pages + Workers + D1, GitHub Actions.

## 2. Repository Layout
```
/content/blogs/{category}/{slug}.md
/content/pages/{slug}.md
/config/site.json  ads.json  menus.json  redirects.json  strings.en.json
/src/layouts  /src/components  /src/pages  /src/styles
/src/lib/{url,seo,schema,geo-schema,linking,redirects,sitemap,amp,readtime,import-xml,svg-icons}.ts
/public/admin  /public/media  robots.txt  ads.txt  site.webmanifest
/workers/{analytics,geo,chat,push,shared,trap,api}
/scripts/{build-redirects,build-sitemaps,indexnow,validate}.ts
/tests/{unit,e2e}
/.github/workflows/{build,schedule,indexnow,lighthouse,backup}.yml
```
